Flisp Emulator is a personal exploration of how low-level systems and user interfaces can meet in a single tool. Inspired by the fascinating FLISP architecture from my studies, I set out to build something modular and robust—leveraging Rust’s safety and modern features.

The project took shape around two core ideas: creating an environment where FLISP code can be assembled and emulated, and making the underlying system transparent and interactive. The result is a tool that brings together a command-line interface for precision and automation, and a terminal user interface for visualization and live debugging.

Building Flisp Emulator has been about learning, experimenting, and making something genuinely useful for anyone curious about architecture, assembly, or just looking for a new way to engage with classic computing ideas.

As I've worked with content management systems (CMS) like WordPress and PayloadCMS, I wanted to test my skills and build my own from scratch. This project was part of a school project where we were learning about the Ruby programming language and the Sinatra web framework.

The CMS includes a custom Object-Relational Mapping (ORM) system that I developed to handle database interactions. This allowed me to gain a deeper understanding of how ORMs work under the hood and how they facilitate communication between the application and the database. The CMS supports basic content management features such as creating, reading, updating, and deleting articles. It also includes user authentication and authorization to manage access to different parts of the CMS.
